# Sample reports

Open these to explore a report before you set up the lake. They hold made-up data for a fictional company (Contoso) and don't need a Fabric connection.

| File | What it shows |
|---|---|
| `M365 Usage Analytics - Sample Data.pbix` | The [M365 Usage Analytics](../README.md#m365-usage-analytics) report with 1,500 synthetic users, 541 of them with a Copilot licence |

Double-click the file to open it in Power BI Desktop. Don't select **Refresh**: the sample data isn't shipped, so a refresh fails. To use your own data, open `M365 Usage Analytics - Fabric.pbit` in the folder above instead.
