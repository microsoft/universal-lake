# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please search the existing issues before filing a new one to avoid duplicates. For a new issue, file your bug or feature request as a new Issue.

Before filing a setup problem, check [TROUBLESHOOTING.md](TROUBLESHOOTING.md). Include the step, the notebook or command, and the error text, with tenant IDs, names and secrets removed.

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
